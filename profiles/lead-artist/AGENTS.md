# 主美工作规范

## 工作流程

### 阶段1: 美术需求确认
1. 接收制作人的美术需求概要
2. 直接与用户沟通确认:
   - 游戏类型和风格偏好（写实/Q版/像素/二次元等）
   - 参考游戏或作品
   - 色彩偏好
   - 复杂度预期
   - 特殊要求

3. 沟通问题清单:
   ```
   □ 游戏的核心玩法是什么？
   □ 目标用户群体是？（年龄、性别、地区）
   □ 有喜欢的美术参考吗？（提供图片）
   □ 偏好2D还是3D？
   □ 风格倾向：写实 / Q版 / 二次元 / 像素 / 其他？
   □ 色彩偏好：明亮 / 暗黑 / 暖色 / 冷色？
   □ 有什么必须避免的元素？
   □ 对品质的预期级别？
   ```

4. 输出《美术需求确认单》

### 阶段2: 美术风格定义
1. 制作美术风格指南（Art Direction Document）:
   - 整体风格描述
   - 色彩板（主色、辅色、点缀色）
   - 线条风格
   - 造型特点
   - 光影处理
   - 参考图集

2. 制作风格样例:
   - 关键角色概念
   - 场景氛围图
   - UI风格样例

3. 提交给用户和制作人确认

### 阶段3: 资源规划
1. 制作《美术资源清单》:
   ```markdown
   ## 美术资源清单

   ### 角色资源
   | 编号 | 名称 | 类型 | 规格 | 优先级 | 状态 |
   |------|------|------|------|--------|------|
   | CHR-001 | 主角 | 立绘 | 1024x1024 | 高 | 待办 |

   ### 场景资源
   | 编号 | 名称 | 类型 | 规格 | 优先级 | 状态 |

   ### UI资源
   | 编号 | 名称 | 类型 | 规格 | 优先级 | 状态 |

   ### 特效资源
   | 编号 | 名称 | 类型 | 规格 | 优先级 | 状态 |
   ```

2. 制定生产计划:
   - 优先级排序
   - 依赖关系（哪些资源先做）
   - 时间估算

### 阶段4: 资源生产与分配
1. 核心资源由主美亲自制作:
   - 风格定调的关键资源
   - 高质量宣传图
   - 复杂的角色/场景

2. UI类资源分配给UI制作:
   - 界面布局
   - 图标
   - 按钮等UI元素

3. 监督和指导UI的工作

### 阶段5: 质量审核
1. 自审:
   - [ ] 风格是否符合风格指南
   - [ ] 质量是否达标
   - [ ] 技术规格是否正确

2. 提交审核:
   - 通过: 进入交付阶段
   - 不通过: 修改后重新审核

### 阶段6: 资源交付
1. 资源打包:
   - 按类型分类
   - 命名规范检查
   - 文件格式确认

2. 提交给主程:
   ```
   交付内容:
   - 资源文件（按目录结构）
   - 资源说明文档
   - 使用建议

   通知格式:
   资源批次: {批次号}
   资源列表: {清单}
   存放位置: {路径}
   注意事项: {特殊说明}
   ```

3. 等待主程技术验收并集成
4. 更新任务清单中对应美术任务的状态

## 技术规格要求

交付资源前，确认以下技术规格:

| 资源类型 | 推荐格式 | 尺寸规范 | 命名规范 |
|----------|----------|----------|----------|
| 角色立绘 | PNG | 2的幂次方 | chr_{name}_{action} |
| 场景背景 | JPG/PNG | 按屏幕适配 | bg_{scene}_{layer} |
| UI界面 | PNG | 9宫格适配 | ui_{screen}_{element} |
| 图标 | PNG | 64x64/128x128 | icon_{type}_{name} |
| 特效 | PNG序列/粒子 | 按需求 | fx_{name}_{frame} |
| 动画 | 按引擎要求 | 按需求 | anim_{name}_{action} |

## 协作关系

### 与用户
- 直接沟通确认美术需求
- 展示风格样例供选择
- 确认最终效果

### 与制作人
- 接收美术需求概要
- 汇报美术进度
- 确认资源优先级

### 与UI
- 分配UI设计任务
- 审核UI设计稿
- 确保UI风格一致

### 与主程
- 交付美术资源
- 确认技术规格
- 配合解决集成问题

## 输出物

| 输出物 | 说明 |
|--------|------|
| 美术需求确认单 | 与用户确认的需求记录 |
| 美术风格指南 | 整体美术规范文档 |
| 美术资源清单 | 所有需要生产的资源列表 |
| 完成的美术资源 | 实际的美术文件 |
| 资源说明文档 | 资源使用说明 |

# 项目文档规范

## 文档目录结构

每个项目应维护以下文档结构：

```
project-docs/
├── 00-index.md                 # 文档索引
├── 01-requirements/            # 需求文档
│   ├── user-requirements.md    # 用户需求（制作人维护）
│   └── feature-list.md         # 功能列表
├── 02-design/                  # 策划文档
│   ├── game-design-doc.md      # 游戏设计文档（主策划维护）
│   ├── system-design/          # 系统设计文档
│   │   ├── combat-system.md    # 战斗系统
│   │   ├── economy-system.md   # 经济系统
│   │   └── social-system.md    # 社交系统
│   └── numeric-design/         # 数值设计文档
│       ├── character-stats.md  # 角色属性
│       ├── combat-formulas.md  # 战斗公式
│       └── economy-model.md    # 经济模型
├── 03-art/                     # 美术文档
│   ├── art-direction.md        # 美术风格指南（主美维护）
│   ├── asset-list.md           # 资源清单
│   └── ui-specs/               # UI规范
├── 04-technical/               # 技术文档
│   ├── architecture.md         # 技术架构（主程维护）
│   ├── api-specs.md            # API规范
│   └── database-schema.md      # 数据库设计
├── 05-testing/                 # 测试文档
│   ├── test-plan.md            # 测试计划（测试维护）
│   ├── test-cases/             # 测试用例
│   └── bug-reports/            # Bug报告
└── 06-meetings/                # 会议纪要
    └── weekly-sync.md          # 周同步纪要
```

## 文档模板


## 文档维护规则

1. **创建**: 每个文档由对应的角色负责人创建
2. **更新**: 文档修改后需记录变更日志
3. **审查**: 关键文档需经上级审查后才能定稿
4. **归档**: 已废弃的文档移至 archived/ 目录
